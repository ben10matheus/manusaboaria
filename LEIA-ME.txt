2. PUBLICAR PELO GITHUB + NETLIFY

a) O repositório já configurado é github.com/ben10matheus/manusaboaria.
   Para atualizar, use PUBLICAR-NO-GITHUB.cmd na pasta principal; os lotes
   permanecem como alternativa de envio manual. Não envie os helpers privados.
b) Envie o CONTEÚDO da pasta "Manu Saboaria\site" para a raiz do repositório.
   Abra site, selecione os arquivos e a pasta assets e faça o upload.
   O arquivo index.html deve aparecer logo na raiz do repositório, junto de
   assets e netlify.toml. Não deixe tudo dentro de outra pasta site.
   Inclua também os demais arquivos entregues, como 404.html e robots.txt.
   A pasta historico fica fora do site e não deve ser enviada ao GitHub.
c) No Netlify, entre na sua conta e abra Projects. Em Add new project,
   escolha Import an existing project e selecione GitHub.
d) Autorize a conexão com o repositório desejado e selecione esse repositório.
e) Confira as configurações deste projeto:
      Base directory: deixe vazio.
      Build command: deixe vazio.
      Publish directory: .
   O ponto significa a raiz do repositório. O netlify.toml já define esse
   diretório. Este site não precisa de npm, dependências ou etapa de build.
f) Confirme a publicação no botão final exibido pelo Netlify (Publish ou
   Deploy site). Aguarde o deploy concluir e abra o endereço netlify.app.

Depois da conexão com o GitHub, novos commits na branch publicada atualizam o
site pelo Netlify. Para alterar nome do projeto ou usar um domínio próprio,
utilize as configurações do projeto no painel do Netlify.

3. ALTERNATIVA: PUBLICAR A PASTA DIRETAMENTE

Entre no Netlify. Em Projects > Add new project > Deploy manually, arraste a
pasta "site" que fica dentro de "Manu Saboaria" para a área de envio.
Ela contém index.html e assets. Envie somente site, sem incluir historico
nem arrastar a pasta de projeto Manu Saboaria inteira.
Também é possível acessar https://app.netlify.com/drop.

Esta pasta já contém os arquivos finais. Para atualizar um site publicado
manualmente, faça as alterações locais e envie novamente a pasta atualizada
pela área de envio da página Deploys do projeto.

4. ATUALIZAR PRODUTOS, PREÇOS E WHATSAPP

O catálogo está em assets/js/products.js. Abra esse arquivo em um editor de
texto ou código. Cada produto tem nome, preço, imagem, descrição e tamanho.

Exemplos de preço no arquivo:
   price:15      corresponde a R$ 15,00
   price:59.90   corresponde a R$ 59,90
   price:null    exibe o produto como valor sob consulta

Use ponto para os centavos, sem o símbolo R$ e sem vírgula. Preserve as aspas,
vírgulas e chaves da estrutura. Salve, recarregue o site e confira o resultado.
O campo phone no início do mesmo arquivo define o WhatsApp da sacola. Os links de contato fixos nas páginas públicas e nos scripts de atendimento também devem ser atualizados se o número mudar.
Use o número completo, somente dígitos: país + DDD + número.
