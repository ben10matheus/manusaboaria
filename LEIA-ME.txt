MANU SABOARIA — PACOTE PARA GITHUB

Esta pasta contém o site completo, com todas as imagens.
Abra index.html para visualizar.

Para o GitHub, envie O CONTEÚDO desta pasta para a raiz do repositório.
index.html, assets e netlify.toml devem ficar juntos na raiz.

Pelo navegador, o GitHub aceita até 100 arquivos por envio.
O passo a passo para enviar em lotes está no README.md.
Também é possível enviar tudo com Git ou GitHub Desktop.

Para o Netlify: diretório de publicação '.', sem comando de build.
Não é necessário instalar nada para o site funcionar.

Esta é a cópia para publicação. A pasta principal de manutenção continua
sendo Manu Saboaria\site na Área de Trabalho.

COMO NOS ENCONTRAR — AGENDA

A página como-nos-encontrar.html reúne os quatro locais fixos, as feiras
temporárias e os botões que abrem cada endereço no Google Maps.

Para atualizar as feiras sem editar código, abra ATUALIZAR-FEIRAS.html
na pasta principal Manu Saboaria, FORA da pasta site. O editor não faz
parte dos arquivos publicados e não deve ser enviado ao GitHub.
Carregue assets/agenda/agenda.js, altere os campos e salve esse arquivo.
No GitHub, substitua somente assets/agenda/agenda.js para mudar a agenda.
O editor não publica sozinho. Feiras encerradas saem automaticamente
da lista atual e ficam no histórico recolhido, pelo dia em Curitiba.
As instruções e as fontes estão em assets/agenda/COMO-ATUALIZAR.txt.
